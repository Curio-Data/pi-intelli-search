## Forced Replay

Before fixture capture, freeze exact workflow/script/prompt hashes, supported arguments, serial/parallel schedule, stable logical operation nodes and repeated-call submission order. Multi-angle and breadth workflows still call every listed `workflowQueries` entry with four attempted pages per query. Include genuine parallel overlap in parallel qualification; do not serialise entire researches to repair suggestions. Each item's schedule is fixed in its versioned run manifest before capture. Never pool observations from different schedules into one estimator. This changes no original H1 population. The schedule is part of the run and fixture manifest, not an amendment of corpus input text. Parallel report producers require unique exact queries; repeated identical research is supported only serially, with prior settlement witnessed. Repeated identical model requests retain ordered occurrences.

Capture the exact initial workspace/index state, real allocations/publications and each real verified suggestion candidate read, including empty reads. Record the ordered membership and producer identity before judge formatting. Recording does not select a different candidate view. During replay, the restricted native read-view controller may await recorded prerequisite publication and select/reorder only unique immutable references from an actual verified read. Baseline metadata remains exact; only declared later-visible block producers may be excluded to recreate the recorded read instant. Missing/window-displaced candidates, foreign/changed baseline entries, ambiguous ownership and invalid dependencies stop/invalidate the block. Suggestions remain active and resolve against the same selected array used in their prompt.

Keep actual requests unchanged. Apply the amendment's typed generated directory-slug/Coordinated Universal Time (UTC) leaf representation before both content-derived node resolution and request hashing. Require exact reconstruction of the complete actual suggestion message from the existing formatter, exact query and verified selected array. Preserve every literal segment and all other request fields. Record original bytes, bindings, producer/view identity and integrity hashes in a new versioned artefact. Generic message/source/code rewriting remains forbidden.

Replay waits are owned, cancellable, finite-budgeted and settled with the operation; no model permit or cache lock is held while waiting. Validate dependency graphs before execution. Report replay-view waits/projections separately: native wall-time replay is not a production-latency comparison or an injected-clock experiment. A fixture/read-view miss invalidates its block even when the supplementary suggestion stage catches the error and returns useful output. Never fall back to live pipeline calls, disable suggestions or label missing observations as zero cost.
