# Approved Cleanup, 4 November 2026

This page records the first approved pass. The subsequent [M4 and cache cleanup](CLEANUP-M4-20261104.md) records the later branch-only scope and retention locations. [Study Closure](CLOSURE.md) records the final worktree retirement. Ignored evidence paths below are historical and no longer exist after that retirement.

This is a directory-footprint comparison, not a claim that 27.10 GiB of physical space became free: shared extents, snapshots and concurrent host activity affect filesystem free space.

## Checks and Execution

The targets resolved to their literal absolute paths on the encrypted repository filesystem. No target root was a symlink or contained a nested mount. The three fixture roots contained no files tracked by their enclosing worktrees. Removal did not follow fixture symlinks or shared dependency links.

Process checks before inventory and immediately before removal found no target use among accessible same-user working directories, file handles, memory maps and selected command markers. Four identified host services had inaccessible handles; an additional inaccessible process was a zombie. These are point-in-time checks, not proof about other users or future process starts. An older monitor process whose working directory was outside the approved scope was left untouched.

The first deletion pass removed the three fixture roots and 6,190 traces, then stopped at a read-only R16 parent directory. The remaining 940 traces were revalidated against the saved inventory. Owner write permission was temporarily enabled on their necessary parent directories, the approved traces were removed, and every original parent mode was restored. No historical helper, test or monitor was executed.

The preservation check covered 28,052 files across source checkouts, tracked publication material, raw benchmarks and the retained monitor files. All 9,902 raw benchmark files passed. Four source files changed concurrently in the active `research-handoff-runner` worktree; those changes were observed, not reverted or written by the cleanup. The three pre-existing policy edits in this worktree remained unchanged through deletion. All 23 checkouts, including the main checkout and 22 linked worktrees, remain registered. No worktree, shared dependency installation or authentication profile was removed.

The audit covered the main checkout, all 22 linked worktrees and adjacent `judge-isolated/` scratch. The removed entries accounted for 27.173 GiB before promotion; the net measured reduction was 27.101 GiB after retained copies, inventories and concurrent activity. Filesystem available space rose by approximately 0.085 GiB between the two `df` observations. That host-wide change cannot be attributed solely to this cleanup.

The main checkout's release/plugin scratch, other worktree scratch, raw benchmarks and publication outputs were not selected for removal.
